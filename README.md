# Colon Cancer Risk Modeling

Synthetic data augmentation and risk prediction for colon cancer using a multi-feature cancer risk factors dataset. The pipeline extracts colon cancer records, expands them with synthetic patients generated by [MOSTLY AI](https://mostly.ai), validates that the synthetic data matches the original distributions, and trains models to predict risk level.

## Repository Contents

| File | Purpose |
|---|---|
| `Data_Extraction_Colon_Cancer.ipynb` | [Extracts colon cancer rows from the full cancer risk factors dataset] |
| `Data_Generation_Colon_Cancer.ipynb` | Trains MOSTLY AI on the colon rows and generates synthetic patients, then combines them with the originals |
| `colon_cancer_extended.csv` | Final dataset: original colon rows + synthetic rows |
| `Data_Analysis_Colon_Cancer.ipynb` | Compares original vs. extended data (means, SDs, KS tests, histograms) |
| `Prediction_Colon_Cancer.ipynb` | Trains and compares 10 classifiers on `Risk_Level`, with overfitting checks and 5-fold cross-validation |

## Workflow

1. **Extraction**: filter `Cancer_Type == "Colon"` from the source dataset and drop `Patient_ID`.
2. **Generation**: train a MOSTLY AI generator on the colon rows only (all features kept), generate `[N]` synthetic rows, and concatenate with the originals. Class balance of `Risk_Level` is checked before and after.
3. **Analysis**: verify the extended data preserves the original distributions:
   - Risk level proportions, original vs. extended
   - Mean and standard deviation for every feature
   - Two-sample Kolmogorov–Smirnov test per feature (p > 0.05 treated as similar)
   - Overlaid histograms for all features
4. **Prediction**: train 10 classifiers, drop the leaking proxy feature (see Results), then check train vs. test gaps and run 5-fold cross-validation.

Run the notebooks in this order. Generation was written for Google Colab (uses `google.colab.files` for download); remove those lines to run locally.

## Methods

- **Synthetic generation:** MOSTLY AI SDK, trained on colon rows only
- **Distribution validation:** KS tests, summary statistics, histogram overlays
- **Models:** Logistic Regression, Decision Tree, Random Forest, Extra Trees, AdaBoost, Gradient Boosting, SVM (RBF kernel), XGBoost, LightGBM, CatBoost
- **Evaluation:** test accuracy, train-vs-test overfitting gap, 5-fold cross-validation (mean and SD)

## Results

### Target leakage found and fixed

The first round of models scored near-perfect (XGBoost 1.000, most others 0.99+). This was caused by target leakage: `Overall_Risk_Score` is a proxy for the target `Risk_Level` and was included in the features. After dropping it and rerunning everything, accuracy fell to realistic levels.

| Model | Accuracy (before) | Accuracy (after) |
|---|---|---|
| XGBoost | 1.000 | 0.870 |
| Gradient Boosting | 0.998 | 0.868 |
| LightGBM | 0.998 | 0.874 |
| CatBoost | 0.998 | 0.884 |
| AdaBoost | 0.998 | 0.882 |
| Decision Tree | 0.998 | 0.732 |
| Random Forest | 0.990 | 0.848 |
| Logistic Regression | 0.974 | **0.896** |
| Extra Trees | 0.938 | 0.842 |
| SVM (RBF) | 0.926 | 0.876 |

### Overfitting and cross-validation (after fix)

- **Best model:** Logistic Regression, 0.896 test accuracy, 0.868 ± 0.026 mean 5-fold CV accuracy. Train accuracy is 0.881, so there is no overfitting.
- **Overfit:** Decision Tree (train 1.000, test 0.732), Random Forest (gap 0.152), and Extra Trees (gap 0.158) memorize the training data.
- **Stable under CV:** all seven models cross-validated (Logistic Regression, Decision Tree, Random Forest, Extra Trees, AdaBoost, Gradient Boosting, SVM) show low fold-to-fold variation (SD 0.015 to 0.036).
- **Takeaway:** a simple linear model matches or beats tree ensembles on this dataset.
